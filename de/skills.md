# Skills

Ein **Skill** ist eine verpackte Fähigkeit: ein Audit ausführen, eine App bauen, eine Idee testen, Kaltakquise schreiben.

**Puzzle-Symbol → "Skills"** zeigt sie als "Integriert" und "Deine Skills" an.

Jeder hat einen Schalter. Wenn du einen ausschaltest, entfernt Taibu ihn in diesem Projekt aus dem Repertoire der KI. **"Bearbeiten"** öffnet den Skill, damit du sein Verhalten ändern kannst.

![Die Skills-Seite](https://raw.githubusercontent.com/taibuchatbot/taibu-docs/main/images/de/16-skills.png)

## Einen ausführen

- Composer → **"Actions"** → einen auswählen. Er öffnet sich in einem eigenen neuen Agenten
- Start → **"Quick actions"**
- Den Slash-Befehl eingeben, zum Beispiel /audit

## Mehr holen

Gib **/find-skills** ein und beschreibe in einfachen Worten, was du brauchst. Taibu durchsucht das Skill-Ökosystem und installiert, was passt.

Neue Skills kommen auch mit App-Updates. Wenn das passiert, zeigt Start "{n} neue Skills verfügbar" mit einem **"Review"**-Button. Nichts wird installiert, bis du bestätigst. Einen Skill, den du selbst bearbeitet hast, überschreibt Taibu nie.
