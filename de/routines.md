# Routinen und Briefings

Eine **Routine** ist ein Prompt, der nach Zeitplan läuft: ein Morgenbriefing, ein wöchentliches Audit, ein Abendjournal.

**Kalender-Uhr-Symbol → "Routinen"**. Die grüne Zahl auf dem Symbol zeigt, wie viele Routinen eingeschaltet sind.

![Die Routinenliste mit einer geöffneten Routine](https://raw.githubusercontent.com/taibuchatbot/taibu-docs/main/images/de/17b-routines-list.png)

## Eine erstellen

**"Routine hinzufügen"**, dann starte mit einer Vorlage oder schreibe deine eigene:

| Vorlage | Läuft |
|---|---|
| Morgenbriefing | Täglich 08:00 |
| Wöchentliches Audit | Montags 09:00 |
| Unbeantwortete Leads | Täglich 09:00 |
| Konkurrenz beobachten | Montags 08:00 |
| Abendjournal | Täglich 18:00 |
| Speicher aufräumen | Sonntags 20:00 |

Lege einen Namen fest, was zu tun ist und einen Zeitplan. Lass "Wenn die App geschlossen war, beim nächsten Start einmal ausführen" angehakt, damit ein verpasster Lauf trotzdem passiert.

## So funktioniert die Planung wirklich

**Routinen laufen nur, wenn Taibu geöffnet ist.** Es gibt keinen Hintergrunddienst und nichts läuft in der Cloud. Schließe die App und nichts startet, bis du sie wieder öffnest.

- Zeiten nutzen die Uhr und Zeitzone deines Computers
- Nachholen führt nur den letzten verpassten Zeitpunkt aus, nie einen Rückstand
- Es läuft immer nur eine Routine gleichzeitig, über alle deine Projekte hinweg
- Routinen laufen für alle Projekte, die du registriert hast, nicht nur für das offene

## Was eine Routine tun darf

Während eines unbeaufsichtigten Laufs behandelt Taibu jedes externe System als **schreibgeschützt**. Es sendet keine E-Mail, veröffentlicht nichts und kauft nichts. Wenn eine Aufgabe etwas senden müsste, schreibt Taibu einen Entwurf in den Postausgang und erwähnt ihn in der Zusammenfassung.

## Briefings

Ein Briefing ist das, was eine Routine erstellt hat. Du findest Briefings auf Start und auf der Seite Routinen. Ungelesene sind fett und haben einen orangefarbenen Punkt. Klicke zum Lesen.

Wenn eine Routine endet, während du arbeitest, erscheint ein Banner und du bekommst eine Desktop-Benachrichtigung.

"Verlauf löschen" leert die Liste. Die Briefing-Dateien bleiben auf der Festplatte.
