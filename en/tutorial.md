# How Taibu works

## The layout

The purple rail on the left is your navigation:

| Icon | Opens |
|---|---|
| House | Home |
| Speech bubbles | Chats, your agents |
| Calendar-clock | Routines |
| Inbox | Outbox, drafts waiting for you |
| Grid | Apps |
| Blocks | Skills |
| People | Team |
| Plug | Connections |
| Brain | My data and goals |
| Question mark | Help |
| Gear | Settings |

Next to it is the sidebar with your project switcher, file search and file tree. The rest is your working area.

## The loop

1. **Give a goal** in plain language.
2. **Taibu turns it into steps** and starts working, creating and editing real files.
3. **Anything going outside** lands in the Outbox for your approval first.
4. **What it learns** goes into memory, so you never explain it twice.
5. **Anything you repeat** becomes a routine that runs on a schedule.

## Good habits

**One agent per goal.** Keep separate jobs in separate agent tabs. Their context stays clean and the answers stay sharp.

**Tell it when it is wrong.** Corrections go into memory and stick.

**Let it ask.** If a request is vague, Taibu asks rather than guessing. Answering takes seconds and saves a wrong result.

**Check the Outbox.** Nothing is sent without you, so drafts wait there until you look.
