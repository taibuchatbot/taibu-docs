# Skills

A **skill** is a packaged ability: run an audit, build an app, pressure-test an idea, write outreach.

**Puzzle icon → "Skills"** lists them as "Built-in" and "Your skills".

Each has a toggle. Turning one off removes it from the AI's repertoire in this project. "Edit" opens the skill so you can change how it behaves.

![The Skills page](https://raw.githubusercontent.com/taibuchatbot/taibu-docs/main/images/16-skills.png)

## Running one

- Composer → **"Actions"** → pick one. It opens in its own new agent
- Home → **"Quick actions"**
- Type the slash command, for example /audit

## Getting more

Type **/find-skills** and describe what you need in plain words. It searches the skills ecosystem and installs what fits.

New skills also arrive with app updates. When they do, Home shows "{n} new skills available" with a "Review" button. Nothing installs until you confirm, and a skill you edited yourself is never overwritten.
