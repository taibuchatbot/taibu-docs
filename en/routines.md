# Routines and briefs

A **routine** is a prompt that runs on a schedule: a morning brief, a weekly audit, an evening journal.

**Calendar-clock icon → "Routines"**

## Creating one

**"Add routine"**, then start from a recipe or write your own:

| Recipe | Runs |
|---|---|
| Morning brief | Daily 08:00 |
| Weekly audit | Mondays 09:00 |
| Unanswered leads | Daily 09:00 |
| Competitor watch | Mondays 08:00 |
| Evening journal | Daily 18:00 |
| Memory tidy-up | Sundays 20:00 |

Set a name, what to do, and a schedule. Leave "If the app was closed, run once on next launch" ticked so a missed run still happens.

## How scheduling really works

**Routines only run while Taibu is open.** There is no background service and nothing runs in the cloud. Close the app and nothing fires until you open it again.

- Times use your computer's clock and timezone
- Catch-up runs the most recent missed occurrence only, never a backlog
- One routine runs at a time, across all your projects
- Routines run for every project you have registered, not only the open one

## What a routine may do

During an unattended run, Taibu treats every outside system as **read-only**. It will not send an email, post anything, or buy anything. If a task needs sending, it writes a draft into the Outbox and mentions it in the summary.

## Briefs

A brief is what a routine produced. Find them on Home and on the Routines page; unread ones are bold with an amber dot. Click to read.

When a routine finishes while you are working, a banner slides in and you get a desktop notification.

"Clear history" empties the list; the brief files stay on disk.
