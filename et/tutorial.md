# Kuidas Taibu töötab

## Vaade

Vasakul olev lilla riba on sinu navigeerimine:

| Ikoon | Avab |
|---|---|
| Maja | Kodu |
| Vestlusmullid | Vestlused, sinu agendid |
| Ruudustik | Äpid |
| Kalendrikell | Rutiinid |
| Märkeloend | Teha, asjad, mida saad teha ainult sina |
| Postkast | Kinnituste postkast, mustandid ootavad sind |
| Pusletükk | Oskused |
| Inimesed | Tiim |
| Pistik | Ühendused |
| Küsimärk | Abi |
| Hammasratas | Seaded, sealhulgas Minu andmed ja eesmärgid, Võtmed ja Mida Taibu mäletab |

Selle kõrval on külgriba projektivahetaja, failiotsingu ja failipuuga. Ülejäänud ala on sinu tööruum.

![Kolm veergu](https://raw.githubusercontent.com/taibuchatbot/taibu-docs/main/images/et/10-layout.png)

## Tsükkel

1. **Anna eesmärk** tavalises keeles.
2. **Taibu teeb sellest sammud** ja hakkab tööle, luues ja muutes päris faile.
3. **Kõik, mis läheb välja**, jõuab enne sinu kinnitamist Kinnituste postkasti.
4. **See, mida ta õpib**, läheb mällu, et sa ei peaks sama asja kaks korda selgitama.
5. **Kõik, mida kordad**, muutub rutiiniks, mis jookseb ajakava järgi.

## Head harjumused

**Üks agent ühe eesmärgi jaoks.** Hoia eri tööd eri agendi vahekaartidel. Nii püsib kontekst puhas ja vastused täpsed.

**Ütle talle, kui ta eksib.** Parandused lähevad mällu ja jäävad sinna.

**Lase tal küsida.** Kui päring on ebaselge, küsib Taibu, mitte ei paku. Vastamine võtab sekundeid ja hoiab vale tulemuse ära.

**Vaata Kinnituste postkasti.** Ilma sinuta ei saada midagi välja, seega mustandid ootavad seal, kuni sa need üle vaatad.
